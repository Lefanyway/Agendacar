# AgendaCar

Sistema web para aluguel e agendamento de carros.

## Objetivo

O AgendaCar permite que usuários visualizem veículos disponíveis, façam reservas e acompanhem seus agendamentos. Também possui uma área administrativa para gerenciamento dos carros cadastrados.

## Stack planejada

### Frontend
- React
- Vite
- React Router DOM
- Tailwind CSS
- Axios
- Framer Motion

### Backend
- Node.js
- Express
- TypeScript
- Sequelize
- PostgreSQL
- JWT
- Swagger

### Inteligência Artificial
- Recomendação de carros
- Chatbot integrado
